# Nacho Fence Website

The public website for **Nacho Fence**, a fence installation and repair
company — built as a fully custom, static site with no framework, plus a
connected AI chat assistant and quote request system.

**Live site:** [nachofence.com](https://nachofence.com)

## Features

- Custom-designed, fully responsive site (HTML, CSS, vanilla JavaScript —
  no frameworks or build step)
- Rotating hero slideshow, service showcase, before/after repair gallery,
  and a 75+ photo project gallery page
- Quote request form that emails submissions directly to the business,
  powered by a connected backend API
- Live AI chat widget for answering visitor questions about services,
  pricing philosophy, and the repair process
- Scroll-triggered reveal animations, mobile-first responsive layout

## Tech stack

- Plain HTML/CSS/JS, deployed as a static site on
  [Vercel](https://vercel.com)
- Custom domain via [Porkbun](https://porkbun.com)
- Backend logic (AI chat + quote emails) lives in a separate project:
  [nacho-fence-ai-api](https://github.com/Ignacio-Penaloza-Data/nacho-fence-ai-api)
